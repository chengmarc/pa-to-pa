# persuader-strategies

One file per persuader strategy. The file goes under "How to negotiate" in the persuader's prompt.

- `no-tactic.md` — baseline: one line, no tactics
- `generic-skilled.md` — a skilled negotiator without either book's tactics, length-matched to the two below
- `fisher-ury.md` — Fisher & Ury, *Getting to Yes*: interests, options, objective criteria
- `voss.md` — Voss, *Never Split the Difference*: labels, mirrors, calibrated questions, Ackerman bargaining

`generic-skilled`, `fisher-ury` and `voss` are kept within a few words of each other (~210), so a difference between
them isn't a difference in prompt length. **The current files are drafts**, to be replaced by the final versions.
